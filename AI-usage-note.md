# AI Usage Note

I used AI throughout the exercise as both a design partner and an implementation assistant.

Before coding, I discussed the problem with an AI chatbot to explore the auto-scheduling algorithm, database design, edge cases, and trade-offs. I challenged and refined the suggestions through several iterations rather than accepting the first solution.

During implementation, I used AI to understand the project context, identify existing components and patterns, and generate implementation prompts. For larger tasks, I reviewed the proposed implementation plan before allowing the code to be generated.

I provided the relevant files and expected workflow when asking AI to implement features. Afterward, I reviewed the generated code, data flow, and behavior myself. When parts were ambiguous, I also used AI to help document and clarify the intent of variables, functions, and code flow.

I treated AI output as a starting point rather than the source of truth: I verified the implementation, questioned its suggestions, and changed the design when my reasoning or the requirements called for a different approach.
